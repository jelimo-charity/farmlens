# FarmLens

**Community-powered climate intelligence for agriculture.**

FarmLens is a web platform that enables farmers to report climate-related crop impacts while providing governments, NGOs, and disaster response organizations with real-time insights through maps, dashboards, and analytics.

By collecting community-generated data, FarmLens helps improve the speed and accuracy of agricultural disaster assessment and supports evidence-based decision-making.

##  Project Goal -Vision

Build a simple, community-powered platform that makes climate impacts on agriculture visible through data, enabling faster and more informed responses to crop losses caused by droughts, floods, pests, and other climate events.




##  Features (MVP)

- Submit climate impact reports
- View reported incidents on an interactive map
- Dashboard with key agricultural insights
- Filter and browse submitted reports
- Basic analytics by county, crop, and climate event
- Report verification workflow
